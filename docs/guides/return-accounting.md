# Karkinos 收益与成本口径

[文档入口](../README.md)

## 今日盈亏

普通跨日持仓：

```text
今日盈亏 = 当前持仓数量 × (当前价格 - 当日基准价)
今日涨跌幅 = 当前价格 / 当日基准价 - 1
```

当日基准通常使用上一交易日可验证的收盘价值。

当日新买入：

```text
当日新买入部分今日盈亏 = 当前市值 - 当日买入总成本
```

可确定的佣金和买入费用计入成本。

## 浮动盈亏

```text
持仓成本额 = 当前持仓数量 × 持仓成本价
浮动盈亏 = 当前市值 - 持仓成本额
浮动收益率 = 浮动盈亏 / 持仓成本额
```

成本来自 Accounting 金融事实，不从市场价格反推。

## 已实现盈亏

来源包括已确认的：

```text
卖出
分红
赎回
其他金融事件
```

已实现盈亏与当前持仓浮动盈亏分开记录。现金流入/流出不直接视为投资收益。

## 现金

现金变化包括：

- 入金 / 出金；
- 买入占用；
- 卖出释放；
- 分红到账；
- 手续费 / 税费。

现金进入净值和资产结构，但不产生市场浮动盈亏。

### 研究回测的现金分红

单次 Dataset 回测可显式选择 `cash_dividends_gross`，默认仍为
`price_only`。该模式只接受已绑定、已实施、日期完整且不含送转的股票现金分红。
它使用登记日收盘成交后的持仓确认资格；除息日增加股息应收及税前收入，
派息日才把应收转为可用现金。登记后卖出不会取消已取得的资格，派息日在
回测结束后时，应收仍计入期末权益。应收确认和到账重放均不得重复入账。

```text
模拟权益 = 可用现金 + 持仓市值 + 股息应收
派息到账：可用现金增加，应收等额减少，权益不重复增加
```

该研究模式按 Decimal 计算税前应得金额，尚未建模个人持股期限税款、补扣、
账户支付舍入或送转股份，也不证明供应商返回了完整的公司行动。TuShare 的
税后字段不能替代具体账户税款。没有官方除息日价格限制参考价时，该标的
当日成交被阻断；不能继续拿上一日裸收盘价作为已核验的涨跌停基准。

分红收入与成交损益分别报告，不伪造 Fill、入金或真实账户流水。报告分别
保存已确认税前收入、已到账现金和未到账应收，保留原 Dataset 的时间及覆盖限制。
这些模拟结果不会更新实际账户账本或授予策略发布权限。

已核验的历史重复买入从原交易日期起作废：历史现金、持仓及收益只计算保留的真实交易。原始记录和旧版补偿记录保留供审计，重建历史时两者都不再参与计算，避免在补偿日期制造资金或份额跳变。重建必须核验完整更正依据，并与当前账本的期末现金、持仓一致；证据缺失或冲突时不提供该历史结果。

## 交易成本

| 类型 | Owner / 用途 |
| --- | --- |
| `expected cost` | Portfolio 的预期交易成本 |
| `simulated cost` | Backtest / Paper 的模拟费用和滑点 |
| `booked cost` | Accounting 的已确认费用和税费 |

## 组合汇总

- 组合收益由同一口径的资产结果汇总。
- 市场价格变化与资金流分开。
- 分红、费用、交易和现金流作为独立金融事件。

## 可追溯字段

```text
value
as-of
price / benchmark source
cost source
financial book
freshness / missing-data state
```

缺少可靠价格、成本或必要金融事实时显示缺失/降级状态，不补造收益。
