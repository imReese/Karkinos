# Karkinos 收益与成本口径

[文档入口](../README.md)

## 今日盈亏

普通跨日持仓：

```text
今日盈亏 = 当前持仓数量 × (当前价格 - 当日基准价)
今日涨跌幅 = 当前价格 / 当日基准价 - 1
```

当日基准通常使用上一交易日可验证的收盘价值。

当日新买入：

```text
当日新买入部分今日盈亏 = 当前市值 - 当日买入总成本
```

可确定的佣金和买入费用计入成本。

## 浮动盈亏

```text
持仓成本额 = 当前持仓数量 × 持仓成本价
浮动盈亏 = 当前市值 - 持仓成本额
浮动收益率 = 浮动盈亏 / 持仓成本额
```

成本来自 Accounting 金融事实，不从市场价格反推。

## 已实现盈亏

来源包括已确认的：

```text
卖出
分红
赎回
其他金融事件
```

已实现盈亏与当前持仓浮动盈亏分开记录。现金流入/流出不直接视为投资收益。

## 现金

现金变化包括：

- 入金 / 出金；
- 买入占用；
- 卖出释放；
- 分红到账；
- 手续费 / 税费。

现金进入净值和资产结构，但不产生市场浮动盈亏。

## 交易成本

| 类型 | Owner / 用途 |
| --- | --- |
| `expected cost` | Portfolio 的预期交易成本 |
| `simulated cost` | Backtest / Paper 的模拟费用和滑点 |
| `booked cost` | Accounting 的已确认费用和税费 |

## 组合汇总

- 组合收益由同一口径的资产结果汇总。
- 市场价格变化与资金流分开。
- 分红、费用、交易和现金流作为独立金融事件。

## 可追溯字段

```text
value
as-of
price / benchmark source
cost source
financial book
freshness / missing-data state
```

缺少可靠价格、成本或必要金融事实时显示缺失/降级状态，不补造收益。
