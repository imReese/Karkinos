# Karkinos 收益与成本口径

[文档入口](../README.md)

本文定义 Karkinos 面向用户展示收益、成本和现金变化时的基础金融语义。

## 今日盈亏

今日盈亏回答：

> 今天发生的市场价格变化，使当前持仓产生了多少价值变化？

对于跨日持有的普通资产：

```text
今日盈亏 = 当前持仓数量 × (当前价格 - 当日基准价)
今日涨跌幅 = 当前价格 / 当日基准价 - 1
```

当日基准通常来自上一交易日可验证的收盘价值。页面应能够追溯当前价格、基准价、时间和来源。

### 当日新买入

当日新买入的持仓不能把买入前的市场涨跌算作账户今日盈亏。

仍持有的当日买入部分应以实际买入成本作为日内基准：

```text
当日新买入部分今日盈亏 = 当前市值 - 当日买入总成本
```

其中可确定的佣金和其他买入费用应计入成本。

## 浮动盈亏

浮动盈亏回答：

> 当前持仓相对于其账面持仓成本赚亏多少？

```text
持仓成本额 = 当前持仓数量 × 持仓成本价
浮动盈亏 = 当前市值 - 持仓成本额
浮动收益率 = 浮动盈亏 / 持仓成本额
```

成本应来自 Accounting 所维护的金融事实。不能用当前市场价格反推一个“看起来合理”的成本价。

## 已实现盈亏

已实现盈亏来自已经确认的卖出、分红、赎回或其他金融事件。

它和当前持仓的浮动盈亏是不同概念，不应混在“今日市场涨跌”中。

当需要展示账户累计盈亏时，应明确它包含哪些已实现和未实现项目，而不要把现金流入流出误当成投资收益。

## 现金

现金没有市场价格波动，因此不产生浮动盈亏。

现金变化属于金融事件，例如：

- 入金和出金；
- 买入占用现金；
- 卖出释放现金；
- 分红到账；
- 手续费和税费扣减。

现金可以进入净值和资产结构，但不能伪装成市场收益。

## 交易成本

Karkinos 应区分：

```text
expected cost   -> 组合构建使用的预期交易成本
simulated cost  -> 回测 / paper 模拟产生的费用和滑点
booked cost     -> Accounting 中已确认的费用和税费
```

配置中的费用模型用于估算和模拟。真实券商或其他已确认来源产生的 booked cost 属于金融事实。

## 组合级汇总

组合级收益必须由同一口径的资产结果汇总，而不是在不同页面重新计算一套定义。

现金流、买卖事件、分红和费用可以作为解释上下文展示，但市场价格变化和资金流必须保持可区分。

## 可追溯性

关键收益数字应能够回答：

```text
value
as-of
price / benchmark source
cost source
financial book
freshness or missing-data state
```

如果缺少可靠价格、成本或其他必要事实，应显示缺失或降级状态，而不是补造收益。
